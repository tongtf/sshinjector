SEQUENCE · TCP DATA PATH

TCP 数据通路时序

一条连接从 SYN 到双向中继 · 出向背压（Channel 128）+ 回向直通 · markEstablished 守卫 / 通道就绪后才发 SYN-ACK / 远端 clean EOF 走 FIN

SSHInjector · 建连：SOCKS 通道就绪后 markEstablished 守卫（唯一建立入口，已 Closed 则就地关通道）才回 rep=0，SYN-ACK 在通道就绪后才发（MSS + 条件 WS）· 出向背压：toSshChannel = SSH_SEND_QUEUE_CAPACITY=128（Socks5ProxyServer.kt:46）满 → 单槽 pendingToSshBlock + 暂停 OP_READ（backpressureLock 保护单槽/标志/OP_READ 切换原子性；预读数据经 pendingConnectData 传递, buffer 不跨线程）→ loopback 满 → forwardToSocks 非阻塞写失败丢弃段 + 不回 ACK（浏览器 TCP 重传兜底, 不阻塞 packetLoop）； 回向 relay 跑 SshIoDispatcher, 回调 (data, off, len) 零拷贝（buffer 由 relay 循环持有、不可保留）, 组包每段 1 分配 1 拷贝； registerTargetEofCallback(localPort) 与 registerTunCallback 同键，远端 clean EOF 由 relay 读到 -1 时 remove-and-invoke（幂等、先于 close）→ closeTcpConnection(graceful=true) 发 FIN+ACK； 回程写 TUN 前按窗口限流（awaitFlowCapacity, flowLock 内 wait/notify；零窗口靠 window update 唤醒, 关闭/ACK 段 notifyAll），每批 RETURN_BATCH_PACKETS=64 段经 TunWriter.writeBlocking 写出，TUN 写严格在 flowLock 锁外（避免与 packetLoop 锁序死锁）
