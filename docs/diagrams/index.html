  • VPN Engine — VpnController 状态机 + TUN
  • 本地代理 — SOCKS5 + SSH 池 + 持久化

KEY FACTS

核心事实

  • 回向直通跳过本地 SOCKS 往返
  • 出向背压: Channel(256) + 非阻塞丢弃/重传兜底
  • SSH 会话池 ×3 + 线性退避重连
  • SSH 池全失败 → VPN 整体自动重连（observeJschConnectionState）
  • 全局设置运行时生效（mtu/keepAlive/IPv6，全局优先 + per-server 回退）
  • lastServerId 持久化 → 开机自启
  • UDP 中继当前不工作

KNOWN DEVIATIONS

代码漂移点

  • UDP relay 已降级: 非 DNS UDP 明确丢弃
  • 非 A/AAAA DNS 走保护 socket 系统直查
